# 🛠️ ToolShare Platform

A web-based tool-sharing and rental platform where users can list tools for rent, browse available tools, place rental orders, and manage their accounts.

## 🌐 Live Demo

👉 **[Visit ToolShare Platform](https://tool-sharing-platform-frontend.vercel.app/)**

### 🚀 Technologies

* **Frontend:** Next.js
* **Backend:** NestJS
* **Database:** PostgreSQL
* **Authentication:** JWT
* **Payment:** Stripe
* **Frontend Deployment:** Vercel
* **Backend Deployment:** Render
* **Online_Database:** NeonDB
